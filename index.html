⌕ Discover collectibles

Searches OpenSea only under the exact Polygon ERC-1155 contract below, then keeps collections whose name or slug contains “untitled” and whose OpenSea unique_item_count is 1–99. It does not substitute total_supply for unique_item_count, because your target is the collection page’s “UNIQUE” count; if that exact field is unavailable, the collection is excluded and its size is treated as unknown. The scanner discovers collection slugs only from NFTs returned by the contract endpoint; it does not hardcode or directly inject any example collection. It does not request NFT event or mint histories, reducing unnecessary API requests. Temporary API keys expire after 7 days; browser CORS and API limits may restrict results. For regular use, keep API keys on a backend.

Temporary keys expire after 7 days. Instant-key requests are limited by OpenSea. If the daily limit is reached, do not keep retrying; use an existing key or create a full key in the OpenSea Developer settings. See the official API-key documentation.

🧾 Evidence & valuation policy

Verified facts

On-chain timestamps, token IDs, mint quantities, transaction hashes, creator wallet where determinable.

Research estimates

Antiquity score, historical importance, metadata quality, and scarcity category. These are assessments, not chain facts.

Market value

Use actual completed sales where possible. Floor prices and seller asks are not proof of fair value; thin markets can have no real liquidity.
